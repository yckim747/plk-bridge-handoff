# PLK 골프 멤버십 광고 랜딩 — 개발팀 전달본

퍼시픽링스코리아 온라인 광고 유입용 랜딩페이지 3장입니다.
운영 환경(CodeIgniter + MariaDB)에 이식해 주세요.

**시연**: [index.html](index.html) 을 열면 3장을 순서대로 눌러 볼 수 있습니다.

---

## 🔴 가장 먼저 봐 주세요 — 지금은 상담 신청이 저장되지 않습니다

`lp-form.html` 의 제출 핸들러는 **입력값을 검증한 뒤 완료 페이지로 이동만** 합니다.
서버로 보내는 코드가 아직 없습니다.

```js
// lp-form.html 하단
if(!ok)return;
// 실제 구현 시: 여기서 hidden 값과 함께 POST → bridge_leads 저장 후 이동
this.querySelector('.f-submit').disabled=true;
location.replace('lp-done.html');            // ← 저장 없이 바로 이동
```

**이 상태로 광고를 집행하면 신청자에게는 '접수 완료'가 뜨는데 데이터는 사라집니다.**
POST 연동을 넣기 전까지는 광고를 돌리지 말아 주세요.

## 1. 받은 파일

| 파일 | 역할 |
|---|---|
| `lp.html` | **광고 랜딩** — 광고 유입 → 상담 신청 단일 목적 |
| `lp-form.html` | **상담 신청 입력** |
| `lp-done.html` | **접수 완료** (`noindex, nofollow`) |
| `img/` | 사진·로고 14개 |
| `index.html` | 시연용 안내 — **운영에 올리지 않으셔도 됩니다** |
| `robots.txt` | 시연본 색인 차단 — **운영에 올리지 않으셔도 됩니다** |
| `MANIFEST.txt` | 파일 목록 + sha256 앞 12자리 |

**HTML 과 `img/` 는 같은 디렉터리에 두어야 합니다.** 페이지가 `src="img/…"` 상대경로로
참조합니다. CSS·JS 는 전부 HTML 안에 인라인이라 별도 파일이 없습니다.

## 2. 페이지 흐름

```
lp.html  ──(상담 CTA 6곳)──▶  lp-form.html  ──(제출)──▶  lp-done.html
```

- 제출 성공은 `location.replace()` 로 이동합니다. **뒤로가기로 폼에 돌아와
  중복 제출하는 것을 막는 장치**이니 페이지 안 완료 화면으로 되돌리지 말아 주세요.
- 입력·완료 페이지에는 GNB 메뉴·플로팅 CTA·전화번호가 없습니다.
  **입력 도중 빠져나갈 경로를 없애 완료율을 올리려는 의도**이니 추가하지 말아 주세요.
- URL 이 3개로 나뉜 이유는 **페이지별 전환율 측정**입니다. 한 URL 안에서 화면만
  바꾸면 '폼까지 왔는데 안 낸 사람'과 '낸 사람'을 갈라낼 수 없습니다.

## 3. 폼 필드 — `lp-form.html`

| `name` | 형식 | 필수 | 비고 |
|---|---|---|---|
| `name` | 문자열 | ✅ | 2자 이상 |
| `phone` | `010-0000-0000` | ✅ | 자동 하이픈, 기본값 `010-` |
| `region` | 자유 입력 문자열 **1개** | — | 예: `수도권, 부산` |
| `page_type` | 고정값 `lp` | — | hidden |
| `utm_source` `utm_medium` `utm_campaign` `utm_content` `utm_term` | 문자열 | — | hidden, 쿼리스트링에서 자동 주입 |
| `referrer` | 문자열 | — | hidden, `document.referrer` |

- 동의 체크박스는 `id="fAgree"` 로 `name` 이 없습니다. 제출 조건으로만 쓰이므로
  **동의 시각을 저장하려면 서버에서 별도로 기록**해 주세요.
- 관심 상품은 받지 않습니다 — **상담사가 통화에서 확인**합니다. 리드 배정·스크립트에 반영해 주세요.
- 동의 전문(`#m-consent`)의 수집 항목은 위 3개 필드와 일치시켜 두었습니다.
  **필드를 더하거나 빼실 때 동의 문구도 함께 고쳐 주세요.**

## 4. 서버 구현 요청 사항

- 접수 엔드포인트: `POST /bridge/lead` (경로는 팀 규칙에 맞게 조정하셔도 됩니다)
- **서버측 검증 필수** — 성함 2자 이상 / 연락처 `^010-\d{4}-\d{4}$` / 동의 여부.
  클라이언트 검증은 우회됩니다
- **중복 접수 방지** — 동일 연락처 24시간 내 재접수 차단 권장
- 저장 테이블: `bridge_leads`, `bridge_lead_consults`
- 실패 시 **완료 페이지로 보내지 말고** 폼에 오류를 표시해 주세요.
  지금 구조는 성공/실패 구분 없이 이동하므로 이 분기를 함께 넣어야 합니다
- 신규 접수 알림(이메일 등)은 담당자와 협의 후

## 5. 이식할 때 지켜야 할 것

- **페이지당 단일 HTML(CSS/JS 인라인)** — 운영 이식성을 위한 결정입니다.
  외부 CSS/JS 로 분리하거나 라이브러리를 추가하지 말아 주세요
- 폰트만 CDN(Pretendard Variable)을 씁니다
- 이미지 경로는 **상대경로 `img/…`** 입니다. 절대경로로 바꾸시려면 3장을 함께 고쳐 주세요
- 새 이미지에는 `loading="lazy"` 와 `width`/`height` 를 반드시 붙여 주세요(레이아웃 밀림 방지)
- `<body>` 의 `word-break:keep-all` — 한글이 단어 중간에서 끊기지 않게 하는 설정입니다. 제거 금지
- 입력 필드 글자 크기는 **16px 미만으로 내리지 말아 주세요** — iOS Safari 가 포커스 시 화면을 자동 확대합니다
- 테마: **라이트가 기본**이고 다크는 푸터 토글로 들어갑니다.
  선택값은 `localStorage['plk-theme']` 에 저장됩니다.
  복원 스크립트는 **`</style>` 직후 `<head>` 안**에 있어야 합니다 — body 하단으로 옮기면 첫 화면이 깜빡입니다
- `lp-done.html` 은 `noindex, nofollow` 입니다. 완료 페이지가 검색에 잡히면 안 됩니다

## 6. 함께 정해 주셔야 할 것

- **측정 태그(GA·GTM)가 들어 있지 않습니다.** URL 은 3개로 나뉘었지만 태그가 없어
  수치가 쌓이지 않습니다. **광고 집행 전에 붙여야 합니다.**
  캠페인 랜딩에서 쓰는 `G-36HR05ZRDD` 를 그대로 쓸지, 별도 GTM 컨테이너를 받을지 알려 주세요
- **개인정보 수집·이용 동의 체크박스가 기본 체크 상태입니다.** 기본값을 유지할지
  해제 상태로 둘지 정책 확인 후 알려 주시면 반영하겠습니다
- **가격 표기에 VAT 조건이 들어 있지 않습니다.** 상품 카테고리마다 조건이 다릅니다
  (개인·법인 VAT 포함 / 소멸형 별도 / 반환형 연회비 별도). 표기 방식을 정해 주세요
