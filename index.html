먼저 봐 주세요 — 지금은 상담 신청이 저장되지 않습니다

입력 페이지의 제출 핸들러가 값을 검증한 뒤 완료 페이지로 이동만 합니다. 서버로 보내는 코드가 아직 없습니다. 이 상태로 광고를 집행하면 신청자에게는 ‘접수 완료’가 뜨는데 데이터는 사라집니다. POST 연동을 먼저 넣어 주세요.

시연할 때 확인해 보실 것

  • 모바일에서 보세요. 45세 이상 모바일 유입이 주 타겟이라 그 폭에 맞춰 만들었습니다
  • 입력 → 완료 이동이 정상인지 (2번에서 제출 → 3번으로 이동, 뒤로가기로 폼에 돌아오지 않음)
  • 연락처 칸은 010- 이 미리 채워져 있고 숫자만 이어 치면 하이픈이 자동으로 붙습니다
  • 테마 토글 — 푸터 맨 아래 버튼. 라이트가 기본이고 선택값은 localStorage 에 남습니다
  • 입력·완료 페이지에 GNB 메뉴·플로팅 CTA·전화번호가 없습니다. 입력 도중 빠져나갈 경로를 없애 완료율을 올리려는 의도이니 추가하지 말아 주세요

이식할 때

  • CSS·JS 는 전부 HTML 안에 인라인입니다. 별도 파일이 없고, 분리하지 말아 주세요
  • HTML 과 img/ 는 같은 디렉터리에 두어야 합니다 — 상대경로로 참조합니다
  • 폰트만 CDN(Pretendard)을 씁니다. 그 밖의 외부 라이브러리는 없습니다
  • URL 이 3개로 나뉜 이유는 페이지별 전환율 측정입니다. 한 URL 안에서 화면만 바꾸면 ‘폼까지 왔는데 안 낸 사람’과 ‘낸 사람’을 갈라낼 수 없습니다

이 페이지(index.html)와 robots.txt 는 시연용입니다. 운영에 올리실 필요는 없습니다. 전달본은 tools/handoff_bridge.py 로 생성되므로, 이 폴더 안에서 직접 고치시면 다음 전달 때 덮어써집니다 — 수정 요청은 알려 주시면 원본에 반영해 다시 보내드립니다.
